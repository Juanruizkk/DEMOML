## ⚡ Resumen de Tools Disponibles

1. **`get_pending_questions`**: Consulta preguntas que requieren revisión humana con botones `[✅ Aprobar]` y `[❌ Rechazar]`.
2. **`get_claims`**: Lista reclamos en gestión, resueltos o urgentes con cálculo de horas de SLA restantes.
3. **`get_claim_detail`**: Detalla un reclamo específico por ID (motivo, SLA, comprador y acciones permitidas).
4. **`get_recent_alerts`**: Muestra las últimas notificaciones y eventos de moderación de la tienda.
5. **`get_store_metrics`**: Resumen cuantitativo de auto-respuestas y volumen de preguntas del día.
